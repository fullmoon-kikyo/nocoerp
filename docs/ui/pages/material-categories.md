# 物料分类：NocoITAM 位置模板适配

Status: Implemented and verified

## 需求与参考

用户要求在「物料管理」下新增独立的「物料分类」，尽可能复制 NocoITAM「主数据 → 位置」模板；已确认本轮包含导入、导出、历史与评论。现有主数据页、分类记录、物料引用及管理员选择保持有效；本轮不分配任何业务角色。

## 数据、权限与服务

- 沿用 `md_material_categories`。新增 `description`、`sortOrder`；对现有 `version` 启用 Core 乐观锁，向前迁移保留既有行和引用。
- 新增类别历史/评论表：类别 ID、事件类型、作者 ID/显示名、变更字段或评论文本、回复 ID、创建/修改/删除时间和版本。历史为分类领域数据，写入与类别修改在同一事务；不替代 Core 权限、数据库或提交回执。
- 新增树变更锁表（单行），新增/重挂/重排/删除/导入在同一事务中先锁定该行，以避免并发重挂形成环。
- 新页面 `/materials/categories`，独立页面权限 `page:materials.categories/access`。`selected`、`tab`、`q`、历史筛选和分页进入 URL。
- 沿用 `composite:masterData.categories`，新增明确的 edit/move/delete/import/export/comment 动作。每次请求通过 Core 身份与操作检查，读写绑定相应分类策略。历史/评论均须先确认其分类可见；物料页签另需物料查看权限。
- 新增未分配的分类管理员/分类查看员角色；保留既有角色、分配及 `member`。在现有角色编辑器显示真实页面和操作。
- 移动不得移入自己或后代；必须有目标父级及所有受影响兄弟的范围权限。重排与版本校验、历史写入原子完成。对话框提供拖动的键盘/触屏等价路径。
- 删除只允许无子级、无物料引用的分类；通过服务检查及外键共同保护，拒绝时不泄漏不可见引用明细。不提供隐式级联。
- 所有写操作使用 `executeIdempotentMutation`，相同操作重试不重复写分类、顺序、历史或评论。删除重放仅返回原 ID 和结果，不返回历史记录字段。
- 评论按当前登录身份记录作者；回复只能关联当前分类的根评论。只有作者可编辑/移除其评论，删除保留墓碑与回复。纯文本渲染，无 HTML 执行。
- CSV 最大 500 行、512 KiB，字段 `code,name,parentCode,description`（接受对应中文表头）。预览不写数据；提交重复校验并在一个事务里完成；循环、缺失父级、越权父级、重复编码及字段错误定位到行。下载使用 UTF-8 BOM、CSV 转义并防止公式执行。

### 接口

| 方法         | 路径（应用 API 下）                                 | 用途                                    |
| ------------ | --------------------------------------------------- | --------------------------------------- |
| GET/POST     | `materialMaster/categories`                         | 保持现有读取/新增，新增备注及顺序       |
| PATCH        | `materialMaster/categories/:id`                     | code/name/description + expectedVersion |
| POST         | `materialMaster/categories/:id/move`                | parentId/index + expectedVersion        |
| DELETE       | `materialMaster/categories/:id`                     | expectedVersion；引用保护               |
| GET          | `materialMaster/categories/:id/history`             | 分类可见前提下，分页读取事件和评论      |
| POST         | `materialMaster/categories/:id/comments`            | body、可选 replyToId                    |
| PATCH/DELETE | `materialMaster/categories/:id/comments/:commentId` | 作者校验及评论版本                      |
| GET          | `materialMaster/categories/export`                  | 当前搜索范围 CSV                        |
| POST         | `materialMaster/categories/import/preview`          | CSV 预览及逐行错误                      |
| POST         | `materialMaster/categories/import`                  | CSV 原子提交                            |

所有接口具有 OpenAPI 声明和严格输入校验；401/403/404/409/校验错误保留当前输入，提供明确提示，不自动覆盖并发修改。

## 页面与交互

工具栏：搜索/筛选、导出、导入、展开/收起全部、创建分类。左侧复制树的卡片、导向线、选择高亮、节点移动反馈；删除放入节点或详情的标准菜单。右侧保持参考的整块白卡：标题/创建子分类/更多菜单，内部基本信息与系统信息卡，下方历史、物料、子分类页签及真实计数。

新增/编辑/移动/导入使用路由对话框，保留树选择和页签。备注支持较长中文；校验失败聚焦到错误。编辑中切换节点、关闭、后退时保护未保存输入。保存后刷新树、详情、计数和历史；选中节点不跳回第一项。首次无选择时选首个可见根节点；明确的不可见/不存在 ID 显示不可用状态，不展示缓存旧数据。

手机：375×667 和 390px，类别选择可折叠，并提供带完整祖先路径的选择器，深层节点无需靠无限缩进辨认。树的缩进最多累加三层；常用展开与选择控件至少 32px，桌面箭头保留原模板的紧凑尺寸。手机使用页面自然滚动，左右独立滚动只在桌面启用。详情与页签纵向排列，物料和子级使用卡片；工具栏收进具名菜单，图标有标签。新增、编辑、导入、评论及移动操作可通过触屏/键盘完成；不存在横向页面溢出。桌面按原参考比较 1440px。

## 验收标准

- D1 导航独立、权限可配置，主数据页不丢失；1440px 的主体结构、层次和尺寸对照 V1/V3 截图。
- D2 选择、深链接刷新、搜索祖先保留、首节点、展开/收起及空/失败/不可用状态正确，无遮挡或旧数据泄漏。
- D3 新增顶级/子级、编辑名称/编码/备注、并发冲突及保存后刷新，分类与主数据页使用同一集合。
- D4 历史/物料/子分类页签显示真实数据，物料权限独立，不把分类共享扩大成关联物料访问。
- D5 拖动与移动对话框均真实持久化；环、越权目标、受影响越权兄弟及并发移动被拒绝。
- D6 CSV 模板、预览、整批导入和导出可用；非法行不部分落库；编码关联和顺序确定；重复提交无重复数据，公式字符安全。
- D7 评论新增、回复、作者编辑/删除、历史筛选与分页生效；历史不可伪造；无权账号不能读取分类历史或代他人修改评论。
- D8 删除保护子分类/物料引用；合法删除、重复请求、选中后刷新正确，其余分类不受影响。
- D9 375/390px、中文 IME、键盘移动/关闭保护及暗色模式可用；复用 Core 权限/数据库/提交能力，无虚假控件或硬编码示例数据。

## 设计评审回应

一次独立设计评审已完成，其结论与处理保留如下。B1 已落实到手机布局要求：32px 触控、三层缩进上限、全路径选择器、手机自然滚动；D9 对应验证。建议同步采纳：筛选导出补全具有导出权限的祖先，缺失祖先权限时拒绝导出；CSV 以单引号转义公式前缀及原单引号，导入按同一约定回读；旧分类的初始历史标记为“既有记录”，保留原有时间与身份，不伪造本轮创建事件。实现使用现有 Loading、PendingButton 和 LongText 组件。

## 实现补充与验收修正

- 关联物料详情复用原有物料表单，通过 `materials/categories/materials/:id` 子路由打开；继承分类页面权限，物料读写仍分别经过业务操作授权，返回保留 `selected/tab/q`，不切换菜单。
- 分类列表及历史复用 Core `resolveListState` 与共享 `ListFeedback/Actions/RefreshIndicator`。首次加载及失败时隐藏创建工具，500 在页头提供重试，403 不提供无效重试；同查询刷新保留授权数据并显示区域刷新反馈。
- 编辑错误在对应字段下显示并关联输入框，修正后清除。取消行内/评论编辑须确认舍弃，下一次编辑仍受保护；创建、编辑和导入沿用路由关闭与后退保护。
- 手机详情字段上下排列，标题独占一行；分类及物料表单的长选项使用统一自适应宽度和换行。真实菜单切换明暗主题及两套预设；不以手动添加 CSS 类代替主题验证。
- 保存、移动、导入及删除使用真实成功反馈；分类提示包含类别名称，批量导入显示数量。确认写入及导出使用共享 PendingButton 反馈。
